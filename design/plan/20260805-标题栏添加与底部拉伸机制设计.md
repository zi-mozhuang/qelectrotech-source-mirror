# 标题栏添加与底部拉伸机制设计方案

> 功能描述：向原理图添加标题栏时，标题栏会被默认拉长（水平方向自适应原理图宽度），并附加到原理图页面的底部。
>
> 本文档梳理该功能的完整代码链路：从用户操作入口 → 状态模型 → 定位计算 → 绘制 → 宽度拉伸算法，并分析其设计要点。

---

## 1. 功能总览

```
用户操作（拖拽 / 属性对话框）
        │
        ▼
ChangeTitleBlockCommand（撤销命令）── 修改 TitleBlockProperties
        │
        ▼
BorderTitleBlock::importTitleBlock() ── 更新模板名与停靠边 m_edge（默认底部）
        │
        ▼
Diagram::drawBackground() ── 每次重绘
        │
        ▼
BorderTitleBlock::draw() ── 计算标题栏矩形（宽=图幅宽，高=模板固有高）
        │
        ▼
TitleBlockTemplateRenderer::render(w) ── 按目标宽度渲染
        │
        ▼
TitleBlockTemplate::render() ── columnsWidth(w) 拉伸列宽，行高保持不变
```

核心设计思想：**标题栏模板本身是一个"弹性网格"**——列宽分为"绝对"、"占总宽百分比"、"占剩余宽百分比"三种类型；渲染时根据目标宽度（原理图图幅宽度）重新计算每列宽度，从而把模板"拉长"填满整行；行高始终是模板内定义的绝对像素值，因此标题栏只在水平方向被拉伸。

## 2. 功能入口（用户操作）

### 2.1 方式 A：从元素面板拖拽标题栏模板

- 拖拽起点：[elementspanel.cpp](sources/elementspanel.cpp) 的 `ElementsPanel::startTitleBlockTemplateDrag()`，构造 MIME 数据：
  - `text`：`TitleBlockTemplateLocation` 序列化字符串
  - 自定义格式 `application/x-qet-titleblock-uri`
- 拖拽终点：[diagramview.cpp](sources/diagramview.cpp) 的 `DiagramView::dropEvent()`，按 MIME 格式分发 → `handleTitleBlockDrop()`：
  1. 解析模板位置 `TitleBlockTemplateLocation`
  2. 若模板属于外部集合，先 `QETProject::integrateTitleBlockTemplate()` 将其集成进当前项目
  3. 通过 `ChangeTitleBlockCommand`（支持撤销）把新模板名写入 `TitleBlockProperties.template_name`
  4. `adjustSceneRect()` 刷新场景矩形

### 2.2 方式 B：图幅属性对话框

- 右键原理图 → "图幅属性"：`DiagramView::editDiagramProperties()` → `DiagramPropertiesDialog`
- `TitleBlockPropertiesWidget` 中勾选显示标题栏、选择模板，同样通过 `ChangeTitleBlockCommand` 提交
- 相关文件：
  - [diagrampropertiesdialog.cpp](sources/ui/diagrampropertiesdialog.cpp)
  - [titleblockpropertieswidget.cpp](sources/ui/titleblockpropertieswidget.cpp)

### 2.3 撤销命令

[changetitleblockcommand.cpp](sources/undocommand/changetitleblockcommand.cpp)：

```cpp
void ChangeTitleBlockCommand::redo() {
	diagram -> showMe();
	diagram -> border_and_titleblock.importTitleBlock(new_titleblock);
	diagram -> invalidate(diagram -> border_and_titleblock.borderAndTitleBlockRect());
}
```

`undo()` / `redo()` 均调用 `importTitleBlock()` 并失效化旧区域，保证撤销后立即重绘。

## 3. 状态与数据模型

| 对象 | 职责 | 关键成员 |
|---|---|---|
| `TitleBlockProperties` | 标题栏的页面级配置 | `template_name`（模板名）、`display_at`（停靠边，**默认 `Qt::BottomEdge`**）、`author/title/folio/context` 等 |
| `BorderTitleBlock`（每个原理图一个，`Diagram::border_and_titleblock`） | 图幅边框 + 标题栏的几何与绘制 | `diagram_rect_`（图幅矩形）、`m_edge`（停靠边）、`m_titleblock_template_renderer` |
| `TitleBlockTemplateRenderer` | 渲染器（带 QPicture 缓存） | `m_titleblock_template`、`m_context` |
| `TitleBlockTemplate` | 模板数据（行列网格 + 单元格） | `columns_width_`（列宽定义）、`rows_heights_`（行高定义）、`cells_` |

关键点：

- 默认值来源：[titleblockproperties.cpp](sources/titleblockproperties.cpp) 构造函数 `display_at(Qt::BottomEdge)`，以及 `fromSettings()` 中 `displayAt` 缺省为 `"bottom"`。**这是标题栏默认附加到底部的根本原因。**
- `importTitleBlock()`（[bordertitleblock.cpp](sources/bordertitleblock.cpp)）将属性写入 `BorderTitleBlock`，当 `m_edge != ip.display_at` 时发出 `displayChanged()` 信号触发重绘。

## 4. "附加到页面底部"的几何计算

`BorderTitleBlock::titleBlockRect()`（场景坐标）：

```cpp
QRectF BorderTitleBlock::titleBlockRect() const
{
	if (m_edge == Qt::BottomEdge)
		return QRectF(diagram_rect_.bottomLeft(),          // ← 锚定图幅左下角
			      QSize(diagram_rect_.width(),           // ← 宽度 = 图幅宽度（拉长）
				    m_titleblock_template_renderer -> height())); // ← 高度 = 模板固有高度
	else
		return QRectF(diagram_rect_.topRight(),           // ← 锚定图幅右上角
			      QSize(m_titleblock_template_renderer -> height(),
				    diagram_rect_.height()));        // ← 停靠右侧时垂直拉长
}
```

设计要点：

- **停靠边两种模式**：`BottomEdge`（底部，默认）与 `RightEdge`（右侧）。底部时标题栏水平铺满图幅宽度；右侧时旋转 90° 垂直铺满图幅高度。
- **高度恒定**：标题栏高度 = `TitleBlockTemplate::height()` = 模板各行高之和（绝对像素，不参与拉伸）。
- **联合矩形**：`borderAndTitleBlockRect() = diagram_rect_ | titleBlockRect()`，`Diagram::adjustSceneRect()` 用它联合 `itemsBoundingRect()` 设置场景矩形，保证标题栏区域落在页面可视范围内。

## 5. "拉长"核心算法：弹性列宽计算

### 5.1 调用链

```
BorderTitleBlock::draw()
  └─ m_titleblock_template_renderer->render(painter, tbt_rect.width())
       └─ TitleBlockTemplateRenderer::render()   // 有缓存分支（此处禁用）
            └─ TitleBlockTemplate::render(painter, context, titleblock_width)
                 ├─ QList<int> widths = columnsWidth(titleblock_width);  // ★ 拉长在此发生
                 └─ 遍历单元格，按新列宽绘制
```

`TitleBlockTemplate::render()`（[titleblocktemplate.cpp](sources/titleblocktemplate.cpp)）中每个单元格的位置/尺寸都基于 `widths` 重新计算（`lengthRange()` 累加列宽），因此列宽变化会整体拉伸所有单元格；高度侧则直接使用 `rows_heights_` 原始值。

### 5.2 三种列宽类型（模板 XML 前缀）

模板文件（`.titleblock`）的 `<grid cols="...">` 支持三种列定义，解析见 `TitleBlockTemplate::loadGrid()`：

| 前缀 | 枚举 | 含义 | 示例 |
|---|---|---|---|
| 无 | `Absolute` | 固定像素宽 | `25` |
| `t` | `RelativeToTotalLength` | 占总目标宽度百分比 | `t22%` |
| `r` | `RelativeToRemainingLength` | 占剩余宽度百分比（吃掉多余空间） | `r100%` |

### 5.3 `columnsWidth(total_width)` 两轮迭代算法

```cpp
QList<int> TitleBlockTemplate::columnsWidth(int total_width) const
{
	// 第一轮：处理 Absolute 与 RelativeToTotalLength
	//   Absolute 列        → final_widths[i] = value（固定）
	//   t 百分比列         → final_widths[i] = total_width * value / 100
	//   累计 abs_widths_sum；记录 relative_columns

	// 剩余宽度 = total_width - abs_widths_sum

	// 第二轮：处理 RelativeToRemainingLength
	//   r 百分比列         → final_widths[i] = remaining_width * value / 100
	//   累计 rel_widths_sum

	// 舍入误差补偿：
	//   difference = total_width - abs_widths_sum - rel_widths_sum
	//   若 |difference| <= 相对列数 * 0.5（每列最多补偿 0.5px）
	//   则逐列 ±1 分摊，保证列宽之和精确等于 total_width
}
```

设计要点：

- **两轮迭代的原因**：`t` 列按总宽计算，必须先算出它们占用的宽度，才能得到"剩余宽度"供 `r` 列使用；`r` 列之间按比例共享剩余空间。
- **舍入补偿**：百分比换算取整必然产生 ±1px 级误差，补偿策略是"小误差（≤ 相对列数×0.5）才补偿"，避免大幅歪曲列宽比例。
- **拉伸方向控制**：默认模板中 `r` 列（标题字段）是唯一弹性列，所以多出的宽度全部由标题列吸收——这正是"标题栏被默认拉长"的直接来源。

### 5.4 默认模板实例分析

`titleblocks/default.titleblock`：

```xml
<grid cols="t22%;r100%;t22%;" rows="25;25;">
```

| 列 | 定义 | 渲染时宽度 | 内容 |
|---|---|---|---|
| 0 | `t22%` | 目标宽度 × 22% | 作者（%author） |
| 1 | `r100%` | 剩余宽度 × 100% = 目标宽度 × 56% | 标题（%title） |
| 2 | `t22%` | 目标宽度 × 22% | 文件名（%filename） |

高度固定为 `25 + 25 = 50px`。若图幅宽 1000px，则三列宽分别为 220 / 560 / 220；若图幅宽 2000px，则变为 440 / 1120 / 440——比例保持，整体水平拉长。

## 6. 绘制流程细节

`BorderTitleBlock::draw()`（[bordertitleblock.cpp](sources/bordertitleblock.cpp)）：

1. 先绘制图幅外框（`diagram_rect_`）、列号/行号表头；
2. 若 `display_titleblock_` 为真：
   - 取 `titleBlockRectForQPainter()`——底部模式返回与显示矩形一致的矩形；右侧模式返回水平化矩形（宽 = 图幅高，高 = 模板高）；
   - **底部模式**：`painter->translate(tbt_rect.topLeft())` 后直接 `render(painter, tbt_rect.width())`；
   - **右侧模式**：平移后再 `painter->rotate(-90)` 渲染（因为模板渲染方向始终是水平的）。

DXF 导出（`drawDxf()`）走同样的 `titleBlockRect()` + `renderDxf()` 路径，保证导出与显示一致。

`TitleBlockTemplateRenderer` 的 QPicture 缓存以"渲染宽度"为键（`m_last_known_titleblock_width`），图幅宽度变化时自动重新渲染；`BorderTitleBlock` 构造函数中已显式 `setUseCache(false)` 以避免旧版 Qt 的渲染崩溃（`QT_VERSION < 4.8` 分支）。

## 8. 设计要点总结

1. **职责分离**：`TitleBlockProperties`（配置）→ `BorderTitleBlock`（几何/绘制）→ `TitleBlockTemplateRenderer`（渲染）→ `TitleBlockTemplate`（数据/布局算法），各层只依赖下一层接口。
2. **弹性布局而非缩放**：标题栏拉伸不依赖 `QPainter::scale`，而是重新计算列宽——文字、线宽、字体不随之变形，保持工程图规范。
3. **锚点定位**：底部模式锚定 `diagram_rect_.bottomLeft`，天然"贴"在页面底部；图幅尺寸变化时标题栏自动跟随。
4. **可配置停靠边**：`display_at`（bottom/right）由 XML 属性 `displayAt` 持久化，模板编辑器可调整。
5. **健壮性**：列宽最小值限制（`MIN_COLUMN_WIDTH 5.0` 等）、舍入误差补偿、撤销/重做支持。
