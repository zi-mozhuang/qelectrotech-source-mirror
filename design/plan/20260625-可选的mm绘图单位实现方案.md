# 可选的绘图单位 — 显示层换算方案

## 需求概述

设置面板可选单位制。单位制只在显示层和输入边界存在，内部运算始终 px。
内部存储始终为 px，`QGraphicsView` 管线不变。单位换算比 `ratio` 仅影响栅格绘制、吸附计算、坐标显示三个显示层面。items、序列化、undo/redo、DXF/数据库输出完全不受影响。

---

## 数学模型

```
items:    A = pos() / scenePos()      — 始终 px
view:     T = B                       — 始终纯缩放/平移矩阵
display:  displayValue = A × ratio    — 显示层换算

ratio = displayValue_per_px_for_this_unit
```

### 换算公式

```
pxValue = QSettings 值（始终整数 px）
displayValue = pxValue × ratio                     — px→显示单位
pxValue = displayValue / ratio                     — 显示单位→px
```

| 单位 | 换算比 (1 px = ?) |
|------|-------------------|
| Pixel (None) | `1.0` |
| Millimeter | `25.4 / 96` |
| Centimeter | `2.54 / 96` |
| Inch | `1.0 / 96` |
| Foot | `1.0 / (12.0 * 96)` |
| Mile | `1.0 / (63360.0 * 96)` |
| Meter | `0.0254 / 96` |
| Kilometer | `2.54e-5 / 96` |
| Microinch | `1.0e6 / 96` |
| Mil | `1000.0 / 96` |
| Yard | `1.0 / (36.0 * 96)` |
| Angstrom | `2.54e8 / 96` |
| Nanometer | `2.54e7 / 96` |
| Micron | `25400.0 / 96` |
| Decimeter | `0.254 / 96` |
| Decameter | `0.00254 / 96` |
| Hectometer | `0.000254 / 96` |
| Gigameter | `2.54e-14 / 96` |
| Astro | `25.4 / 96 / 149597870700.0 / 1000.0` |
| Lightyear | `25.4 / 96 / 9.4607304725808e15 / 1000.0` |
| Parsec | `25.4 / 96 / 3.08567758149137e16 / 1000.0` |

### 核心公式（栅格/吸附）

```
gridPx = Xgrid / ratio                    — 用户设 10mm → gridPx = 10/0.2646 = 37.8px
snappedPx = round(mousePx / gridPx) × gridPx
```

## 数据流

```
QSettings                  UnitConverter
  diagrameditor/             instance()
  unit_system                ratio()
      │                          │
      └────── setSystem() ───────┘
                                    │ ratio()
          ┌─────────────────────────┘
          ▼           ▼           ▼
    drawBackground  snapToGrid  坐标显示
    gridPx =        gridPx =    value =
    Xgrid/ratio     Xgrid/ratio  pos*ratio
```

### 加载项目

```
XML <element x="100" y="200"/>
  ↓
Diagram::fromXml 加载 item
  ↓
item->pos() = (100, 200)   ← px，无转换
```

### 保存项目

```
item->pos() = (100, 200)   ← px，无转换
  ↓
item->toXml 写入 x="100" y="200"
```

### 单位切换

```
ratio1 → ratio2
  │
  ├── items: 不动（场景坐标始终 px）
  ├── QSettings: 不动（栅格值始终 px）
  ├── view transform: 不动（B × D 取消，维持 B）
  └── gridPx: 自动用 Xgrid / ratio2 计算
```

QET::UnitSystem UnitConverter::system() const { return m_system; }

void UnitConverter::setSystem(QET::UnitSystem sys)
{
    // clamp valid range to prevent QSettings dirty values from OOB
    sys = qBound(QET::UnitSystem::None, sys, static_cast<QET::UnitSystem>(QET::UnitSystem::Parsec));
    if (m_system != sys) {
        m_system = sys;
        emit unitSystemChanged();
    }
}

qreal UnitConverter::ratio() const {
    return unitFactor[m_system];
}

qreal UnitConverter::toDisplay(qreal px) const {
    return isPixelMode() ? px : px * unitFactor[m_system];

qreal UnitConverter::fromDisplay(qreal display) const {
    return isPixelMode() ? display : display / unitFactor[m_system];
}

QPointF Diagram::snapToGrid(const QPointF &p)
{
    auto *uc = UnitConverter::instance();

    QSettings settings;
    qreal ratio = uc->ratio();

    //Return a point rounded to the nearest pixel
    if (QApplication::keyboardModifiers().testFlag(Qt::ControlModifier)) {
        qreal unitPx = uc->fromDisplay(1.0);
        qreal p_x = qRound(p.x() / unitPx) * unitPx;
        qreal p_y = qRound(p.y() / unitPx) * unitPx;
        return QPointF(p_x, p_y);
    }

    qreal xGrid = settings.value(QStringLiteral("diagrameditor/Xgrid"),
                                 Diagram::xGrid).toReal() / ratio;
    qreal yGrid = settings.value(QStringLiteral("diagrameditor/Ygrid"),
                                 Diagram::yGrid).toReal() / ratio;

    //Return a point snapped to the grid
    qreal p_x = qRound(p.x() / xGrid) * xGrid;
    qreal p_y = qRound(p.y() / yGrid) * yGrid;
    return QPointF(p_x, p_y);
}

### Phase 3 — 坐标显示

**原则**：单位制只在显示层和输入边界存在，内部运算始终 px。
- **显示层**：`toDisplay(px)` → mm
- **输入边界**：用户输入 mm → `fromDisplay(mm)` → px 存储
- **内部运算**：比较/undo/setValue 保持 px vs px，**不改代码**

pixel mode（ratio=1.0）时 `toDisplay`/`fromDisplay` 直接返回原值。

```cpp

qreal displayX = uc->toDisplay(item->pos().x());  // 显示层转换
qreal displayY = uc->toDisplay(item->pos().y());

// sources/ui/unitspinbox.cpp
#include "unitspinbox.h"
#include "../units.h"

UnitSpinBox::UnitSpinBox(QWidget *parent)
    : QDoubleSpinBox(parent)
    , m_uc(UnitConverter::instance())
{
    setDecimals(2);

    connect(m_uc, &UnitConverter::unitSystemChanged,
            this, &UnitSpinBox::onUnitSystemChanged);
}

void UnitSpinBox::onUnitSystemChanged()
{
    // Must force textFromValue recalculation; interpretText() alone is insufficient.
    // setValue(value()) re-evaluates the new display string via textFromValue().
    setValue(value());
}

QString UnitSpinBox::textFromValue(double pxValue) const
{
    double displayValue = m_uc->toDisplay(pxValue);
    return QString::number(displayValue, 'f', 2);
}

double UnitSpinBox::valueFromText(const QString &text) const
{
    double displayValue = QDoubleSpinBox::valueFromText(text);
    return m_uc->fromDisplay(displayValue);
}

void UnitSpinBox::stepBy(int steps)
{
    if (m_uc->isPixelMode()) {
        QDoubleSpinBox::stepBy(steps);
        return;
    }
    double stepPx = m_uc->fromDisplay(1.0);
    setValue(value() + steps * stepPx);
}
```

**核心设计**：

| 层 | 值/类型 | 说明 |
|---|---|---|
| 内部存储 | `value()` = px | setValue(px) / value() 返回 px，调用方无需转换 |
| 显示层 | `textFromValue(px)` → mm 字符串 | 用户看到 mm |
| 输入边界 | `valueFromText("10.0")` → px | 用户输入 mm，自动转 px 存储 |

#### 3.8 单位切换时的 SpinBox 刷新

用户修改设置面板单位制后：
1. `applyConf()` 调 `UnitConverter::instance()->setSystem(newSys)`
2. setSystem emit `unitSystemChanged()`
3. 每个 UnitSpinBox 的 `onUnitSystemChanged()` 执行 `setValue(value())` 触发 `textFromValue` 重算
4. 显示文字自动更新为当前单位

打开的 dialog 若包含 UnitSpinBox，需要收到 signal。因 phase 0 的 connect 在 SpinBox 构造时建立，
dialog 构造在 `applyConf()` 之前已完成。单位切换时已打开的 dialog 不会收到 signal。

**解决方案**（当前首版不实现）：QETApp 调 systemChange 时遍历所有顶级窗口，递归找 UnitSpinBox 触发
重新显示。首版可接受已打开 dialog 不刷新（关闭重开生效）。
