# 标题栏右下角覆盖模式实现方案（缩减版）

## Summary

为标题栏（cartouche）新增**覆盖（overlay）显示模式**：与 `display_at` 正交组合——BottomEdge + overlay → 标题栏不拉伸，固定叠加在页面**右下角**；RightEdge + overlay → 固定叠加在页面**右上角**；不勾选 overlay 则保持原有拉伸行为。覆盖模式下标题栏**绘制在最底层**（元素之下，纸色遮罩防网格穿透），尺寸由模板列设定推导（`minimumWidth()`），全相对列模板回退到公共常量 `DEFAULT_PREVIEW_WIDTH`。

**宽度来源（本次缩减的核心）**：不新增任何模板 XML 属性。每个模板的列设置（绝对 px / 百分比）都是确定的，现有 `TitleBlockTemplate::minimumWidth()`（[titleblocktemplate.cpp#L965-L984](../../sources/titleblocktemplate.cpp#L965-L984)）即可从列设置推导出唯一宽度：`sum(绝对列) / (1 − sum(百分比列)/100)`。仅当模板完全没有绝对列（如随附 `default.titleblock` 全相对列）时返回 0，此时回退到公共常量 `DEFAULT_PREVIEW_WIDTH`（== 600，原为 [templateview.cpp#L30](../../sources/titleblock/templateview.cpp#L30) 私有 `#define`，Phase 1 提升为公共常量后覆盖分支与模板编辑器共用同一来源）。

**相对上一版方案的削减**：
- 删除 `naturalWidth()` 新方法与 `recommendedwidth` XML 属性、`default.titleblock` 修改；
- 删除 `TitleBlockProperties::toSettings/fromSettings` 的 overlay 读写；
- 删除双击命中优先级修正（旧 Phase 6）；
- const 修正从 4 个方法缩减为 3 个（`columnTypeCount`/`columnTypeTotal`/`minimumWidth`，纯签名改动）。

改动面：**10 个文件**，其中 4 处为单行级修改。

### Phase 1 — `DEFAULT_PREVIEW_WIDTH` 提升为公共常量 + 宽度查询方法 const 修正

**文件：`sources/titleblock/templateview.cpp`** 删除 L30 `#define DEFAULT_PREVIEW_WIDTH 600`。

**文件：`sources/titleblocktemplate.h`** 顶部（include 区后）新增：


> 选 [titleblocktemplate.h](../../sources/titleblocktemplate.h)（而非 templateview.h）作常驻点：bordertitleblock.cpp 与 templateview.cpp（经 `templateview.h` 的 `#include "../titleblocktemplate.h"`）两路都已 include 它，**零新增 include**；若放 templateview.h 则 bordertitleblock.cpp 需额外引入 `QGraphicsView` 重型视图头。仍用 `#define` 保留项目既有形式（[templateview.cpp#L30](../../sources/titleblock/templateview.cpp#L30) 原样搬家），只改位置不改写法。

### Phase 2 — `BorderTitleBlock` 覆盖几何与最底层绘制

**文件：`sources/bordertitleblock.h`**

1. public 区新增访问器：

```cpp
		/// @return true si le cartouche est affiche en overlay
		bool titleBlockIsOverlay() const {
			return(display_overlay_); }

		/// @return true if overlay is enabled AND not degraded
		/// (i.e. titleblock fits within diagram dimensions)
		bool isOverlayActive() const {
			if (!display_overlay_)
				return false;
			int tpl_h = m_titleblock_template_renderer -> height();
			int natural = m_titleblock_template_renderer
			      -> titleBlockTemplate() -> minimumWidth();
			if (natural == 0)
				natural = DEFAULT_PREVIEW_WIDTH;
			if (m_edge == Qt::BottomEdge)
				return natural <= diagram_rect_.width()
				       && tpl_h <= diagram_rect_.height();
			return natural <= diagram_rect_.height()
			       && tpl_h <= diagram_rect_.width(); }
```

2. private 区 `display_titleblock_`（L280）旁新增：

```cpp
		bool display_titleblock_;
		bool display_overlay_;   ///< overlay mode
```

3. 构造函数（`display_titleblock_ = true;` 处，bordertitleblock.cpp L70-71）追加初始化：

```cpp
	display_titleblock_ = true;
	display_overlay_ = false;
```

4. `titleBlockRect()`（L88-100）— **overlay 几何计算与退化判断合并到一个函数内联完成**（不再拆分独立 `titleBlockOverlayRect()` 与调用方两次查询）。函数开头统一取 `tpl_h`/`natural`，overlay 且放得下 → 直接返回角落矩形；否则天然落到原有拉伸分支：

```cpp
QRectF BorderTitleBlock::titleBlockRect() const
{
	int tpl_h = m_titleblock_template_renderer -> height();
	int natural = m_titleblock_template_renderer
		      -> titleBlockTemplate() -> minimumWidth();
	if (natural == 0)
		natural = DEFAULT_PREVIEW_WIDTH;

	if (m_edge == Qt::BottomEdge)
		return (display_overlay_
			&& natural <= diagram_rect_.width()
			&& tpl_h <= diagram_rect_.height())
			? QRectF(diagram_rect_.bottomRight()
				 - QPointF(natural, tpl_h),
				 QSizeF(natural, tpl_h))
			: QRectF(diagram_rect_.bottomLeft(),
				 QSize(diagram_rect_.width(), tpl_h));
	return (display_overlay_
		&& natural <= diagram_rect_.height()
		&& tpl_h <= diagram_rect_.width())
		? QRectF(QPointF(diagram_rect_.right() - tpl_h,
				 diagram_rect_.top()),
			 QSizeF(tpl_h, natural))
		: QRectF(diagram_rect_.topRight(),
			 QSize(tpl_h, diagram_rect_.height()));
}
```

> - **退化判定方向**：放得下（`natural <= 宽 && tpl_h <= 高`）才走 overlay；任一超过 → 拉伸分支
> - `natural == 0`（全相对列模板）回退 `DEFAULT_PREVIEW_WIDTH`
> - RightEdge 拉伸分支与原有代码一致：`topRight` 锚点、`Size(tpl_h, 图幅高)`

5. `titleBlockRectForQPainter()`（L123-134）**减少重复**：overlay 且非退化（即可用 `isOverlayActive()`）时直接复用 `titleBlockRect()` 结果做旋转锚点变换，不重新计算尺寸，也不重新做退化判断。RightEdge 旋转前宽高互换，且 **QPainter 原点必须为显示区域的右上角**（即旋转 -90° 后标题栏向图幅内部延伸）：

前：

```cpp
	if (m_edge == Qt::BottomEdge)
		return titleBlockRect();
	else
		return QRectF (diagram_rect_.bottomRight(),
			       QSize(diagram_rect_.height(),
				     m_titleblock_template_renderer -> height()
				     ));
```

后：

```cpp
	if (m_edge == Qt::BottomEdge)
		return titleBlockRect();
	QRectF r = titleBlockRect();
	return isOverlayActive()
		? QRectF(r.bottomLeft(),
			 QSizeF(r.height(), r.width()))
		: QRectF(diagram_rect_.bottomRight(),
			 QSize(diagram_rect_.height(),
			       m_titleblock_template_renderer -> height()
			       ));
```

> `r = titleBlockRect()` 在 overlay 生效时即 overlay 矩形。
> BottomEdge overlay：直接返回 `titleBlockRect()`。
> RightEdge overlay：**旋转锚点必须为 `r.bottomLeft()`（非 `(r.right(), r.top())`）**。draw() 的旋转原点 = `tbt_rect.topLeft()`，`rotate(-90)` 将局部 `(x,y)` 映射为 `(y,-x)`，故渲染盒落在锚点右上：`x∈[0,r.width()], y∈[-r.height(),0]`。取锚点 `(right-tpl_h, top+natural)`（即 `r.bottomLeft()`）后，渲染盒恰覆盖 `[right-tpl_h,right]×[top,top+natural]` = overlay 显示区域。若用 `(r.right(), r.top())`，旋转后盒超出图幅右上、未落入设定区域。
> RightEdge 非 overlay：原拉伸 painter 矩形（`bottomRight` 锚点，向图幅外延伸）。

6. `draw()`（L588-609）：覆盖模式先铺纸色遮罩，**但遮罩必须用 `titleBlockRect()` 获取实际显示区域**——`tbt_rect` 的 `topLeft` 是旋转锚点，对 RightEdge 并非显示区域。旋转分支不变：

前：

```cpp
	if (display_titleblock_) {
		QRectF tbt_rect = titleBlockRectForQPainter();
		if (m_edge == Qt::BottomEdge)
		{
```

后：

```cpp
	if (display_titleblock_) {
		QRectF tbt_rect = titleBlockRectForQPainter();
		// 遮挡网格线
		if (isOverlayActive())
			painter -> fillRect(titleBlockRect(),
					    Diagram::background_color);
		if (m_edge == Qt::BottomEdge)
		{
```

> 退化时 `isOverlayActive()` 返回 false，不铺遮罩——走原拉伸绘制路径。

7. `exportTitleBlock()`（L302）`ip.display_at = m_edge;` 之后：

```cpp
	ip.display_at = m_edge;
	ip.overlay = display_overlay_;
```

8. `importTitleBlock()`（L329-333）：

前：

```cpp
	if (m_edge != ip.display_at)
	{
		m_edge = ip.display_at;
		emit(displayChanged());
	}
```

后：

```cpp
	if (m_edge != ip.display_at || display_overlay_ != ip.overlay)
	{
		m_edge = ip.display_at;
		display_overlay_ = ip.overlay;
		emit(displayChanged());
	}
```

## 构建与验证计划

```sh
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release \
  -DQt5_DIR=/usr/lib/cmake/Qt5 -DBUILD_WITH_KF5=OFF -DPACKAGE_TESTS=ON
cmake --build build -j$(nproc)
```

运行验证：
1. 拖入标题栏，默认仍拉伸到底部（回归无变化）。
2. 双击标题栏 → 勾选"不拉伸标题栏" → 确定：标题栏以模板设定宽固定于右下角（BottomEdge），元素可压在其上；网格在标题栏区域被纸色遮住。
3. 切换位置为"右"并保持勾选"不拉伸" → 标题栏固定于右上角，**纵向排列**（旋转 -90°，与拉伸模式旋转方向一致）。
4. 取消勾选 → 恢复原有拉伸行为，sceneRect 即时收缩/恢复（Phase 3 生效）。
5. 保存 .qet 重开：overlay 保持；用旧版语义检查 XML，仅多一个 `overlay="true"` 属性。
6. 打印预览：勾选/取消"打印标题栏"，overlay 下页面底部均不被裁切。
7. 随附 default.titleblock（全相对列）：overlay 宽回退 `DEFAULT_PREVIEW_WIDTH`（600），不出现 0 宽退化。
8. 极端小页面（图幅宽/高 < 模板 natural/tpl_h）：`titleBlockOverlayRect()` 返回空，自动退化为原拉伸模式（BottomEdge 铺满底部、RightEdge 铺满右侧），无列溢出，无纸色遮罩。
9. `ctest --output-on-failure` 无回归。

## Rejected Alternatives

1. **`drawForeground` 最上层覆盖**：用户明确要求覆盖模式绘制在最底层。
2. **新增 `recommendedwidth` 模板属性 + `naturalWidth()`**：模板列设定已含确定宽度信息，`minimumWidth()` 足够，新增属性属冗余。
3. **持久化编辑器预览宽 `preview_width_`**：`preview_width_` 是视图层运行时成员（用户可在模板编辑器内改），入库需改 loadGrid/saveGrid，改动大于收益，仍不做。本次只提升其默认值常量 `DEFAULT_PREVIEW_WIDTH`（编译期宏，非成员值，无需持久化），覆盖回退语义与"编辑器默认预览宽"一致。
4. **组合框第三项替 overlay**：overlay 与 edge 正交（Bottom+overlay=右下，Right+overlay=右上），用独立复选框而非组合框第三项，避免 edge 选择被覆盖。
5. **修改 `Qt::Edge` 语义复用 RightEdge 表达覆盖**：语义混淆且破坏现有右侧拉伸模式。
